# PCB Design and Validation

This directory contains printed circuit board (PCB) design projects and
laboratory reports completed as part of undergraduate and graduate-level
electrical engineering coursework.

The work in this section demonstrates experience with schematic capture,
multi-layer PCB layout, fabrication, assembly, electrical validation,
and signal integrity analysis.

## Areas of Focus

- Schematic design and component selection
- Multi-layer PCB layout using Altium Designer
- Power distribution network (PDN) design
- Signal integrity and noise analysis
- Decoupling and grounding strategies
- Embedded system integration
- Hardware validation and debugging

## Structure

### boards/
Contains complete custom PCB designs, including schematics, layouts,
assembly photos, firmware (when applicable), and full technical reports.

Featured projects include:
- Golden Arduino (custom Arduino-compatible microcontroller board)
- Instrument Droid (multi-function measurement and test shield)

### labs/
Contains supporting laboratory reports focused on specific PCB and
measurement topics such as decoupling, trace resistance, differential
signaling, and power rail noise.

These labs document experimental methods, data analysis, and
design best practices.

## Tools and Technologies

- Altium Designer (schematic capture and layout)
- Oscilloscopes, DMMs, logic analyzers
- Function generators and programmable power supplies
- Arduino and ATmega-based platforms
- Manual and reflow soldering techniques

## Validation and Documentation

All featured boards were assembled and electrically validated through:
- Functional testing and firmware verification
- Signal integrity and PDN measurements
- Comparison against reference designs
- Formal technical reporting

Supporting scope captures, plots, and analysis are included
in individual project folders.
