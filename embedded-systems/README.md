# Embedded Systems

STM32 firmware projects in C on ARM Cortex-M, covering real-time task
design, peripheral drivers, and graphical user interfaces.

## [Labyrinth - FreeRTOS Tilt Maze](rtos-labyrinth-stm32/)
**FreeRTOS, STM32F429, SEGGER SystemView**

A six-task FreeRTOS tilt-maze game with gyro-driven physics, mutex and
event-flag coordination, and SystemView-profiled scheduling. ECEN 3753,
Spring 2026.

📂 Project Folder
`embedded-systems/rtos-labyrinth-stm32/`
